# NetLogger original check-in files — upload staging area

This folder is the collection point for the **original NetLogger check-in files**
used by the Roseland Amateur Radio Club net reports. Files placed here are
source records, **not website content**.

## How to upload

1. Open this folder in GitHub and choose **Add file → Upload files**.
2. Upload the original NetLogger check-in files from each laptop. Keep the
   original file contents, filenames, and extensions unchanged.
3. You may also upload **one ZIP archive per laptop** containing its original
   CheckIns directory. This is useful if multiple laptops have files with the
   same names, and preserves the original folder structure. Use distinct
   archive names such as `netlogger-laptop-01.zip`,
   `netlogger-laptop-02.zip`, etc.
4. Upload in multiple batches if necessary. Please do not overwrite one
   laptop's data with another laptop's files.
5. When all available files are uploaded, tell me **"NetLogger uploads complete"**.

There is no need to clean the records, change their format, consolidate the
laptop files, or identify missing net dates yourself.

## What happens after uploads are complete

- Inventory all supplied files and identify their original NetLogger formats.
- Compare the recovered net dates with the dated screenshots in
  `assets/img/net-YYYY-MM-DD.png`.
- Produce a date-by-date gap report, including duplicates and conflicting
  copies from different laptops.
- Use the **original NetLogger check-in files** as the sole source of new
  database records. No OCR output will be used as source data.
- For dates without original logs, identify nets to enter manually using
  verified information.
- Replace the experimental OCR-based database in a separate, reviewed PR,
  without changing the existing production net reports until approved.

## Public repository notice

**This GitHub repository is public.** The leading underscore keeps this
directory out of the usual Jekyll website build, but it **does not make the
files private on GitHub**. Before uploading, ensure files do not contain
private phone numbers, email addresses, or other information that should not
be made public. If unredacted files contain private details, use a private
repository or private storage instead; let me know before uploading them.

No new database files are generated by merely placing source files here.
