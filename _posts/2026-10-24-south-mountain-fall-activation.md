On Saturday, October 24, 2026, members of the Roseland Amateur Radio Club, the West Essex Amateur Radio Club (WEARC), New Providence Amateur Radio Club (NPARC), and other local amateur radio groups met at Bramhall Terrace in South Mountain Reservation, Maplewood, New Jersey, for another outdoor operating session. The group was on site from 9 AM to 1 PM Eastern, setting up portable stations and enjoying an autumn morning on the air.

The weather made for a pleasant fall gathering. Temperatures were in the mid-40s at the start and rose into the upper 50s by early afternoon, with breaks of sunshine, light winds, and colorful foliage throughout the reservation.

Radio conditions were favorable, too. The HF bands were in good shape, including an opening on 10 meters. Operators worked CW, voice, and digital modes, making many contacts during the four-hour session. Between contacts, there was plenty of opportunity to compare equipment, discuss antennas, and see how different portable setups performed in the field.

Around 10 AM Eastern (14:00 UTC), the solar flux index was near 100, and NOAA's morning space-weather outlook forecast a quiet planetary Kp near 1 for the surrounding three-hour period. No significant HF radio blackouts had been reported. Despite a cautious outlook for the highest HF bands, operators found 10 meters open—an example of why it's always worth checking the bands firsthand. (<a href="https://www.arrl.org/news/the-arrl-solar-update-48" target="_blank" rel="noopener noreferrer">ARRL Solar Update, October 23, 2026</a>)

The event was as much about getting together as it was about getting on the air. The informal format gave participants a chance to exchange ideas, help one another with equipment, and enjoy amateur radio outside the shack.

This will likely be our last outdoor operating event of 2026, but there are additional indoor activities planned for November and December. We look forward to returning to outdoor operations when the warmer weather arrives in spring 2027.

A sincere thank-you to everyone who participated in the South Mountain activation events throughout 2026. Your participation, camaraderie, and willingness to share equipment and ideas made the spring, summer, and fall weekends special. Thanks as well to Maurice for documenting this gathering with his photographs. We look forward to seeing everyone at the indoor events and back at South Mountain together next spring.

(function () {
  const gallery = document.getElementById('south-mountain-gallery-2026');
  const viewer = document.getElementById('south-mountain-viewer-2026');
  if (!gallery || !viewer || typeof viewer.showModal !== 'function') return;

  const photos = Array.from(gallery.querySelectorAll('a[data-full]'));
  const large = document.getElementById('south-mountain-photo-large');
  const count = document.getElementById('south-mountain-photo-count');
  let current = 0;

  function display(index) {
    current = (index + photos.length) % photos.length;
    const link = photos[current];
    large.src = link.dataset.full;
    large.alt = 'Full-size photo ' + (current + 1) + ' of ' + photos.length + ' from the South Mountain event';
    count.textContent = (current + 1) + ' / ' + photos.length;
  }

  photos.forEach(function (link, index) {
    link.addEventListener('click', function (event) {
      event.preventDefault();
      display(index);
      viewer.showModal();
    });
  });

  document.getElementById('south-mountain-photo-prev').addEventListener('click', function () { display(current - 1); });
  document.getElementById('south-mountain-photo-next').addEventListener('click', function () { display(current + 1); });
  document.getElementById('south-mountain-photo-close').addEventListener('click', function () { viewer.close(); });
  viewer.addEventListener('click', function (event) {
    if (event.target === viewer) viewer.close();
  });
  viewer.addEventListener('keydown', function (event) {
    if (event.key === 'ArrowLeft') { event.preventDefault(); display(current - 1); }
    if (event.key === 'ArrowRight') { event.preventDefault(); display(current + 1); }
  });
  viewer.addEventListener('close', function () {
    large.removeAttribute('src');
  });
}());
</script>
